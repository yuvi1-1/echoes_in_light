## About

This portfolio is a personal digital space for **Yuvraj Pegu**, a Computer Science Engineering student and creative technologist based in India.

I build software in code and experiment with light, sound, visuals, and interactive experiences outside traditional software development.

The site brings together three parts of my work:

- **Code** — software engineering, web applications, AI/ML, cloud, and DevOps
- **Light** — projection mapping, visual experiments, generative visuals, and creative technology
- **Sound** — music, guitar, and the artists and sounds that influence my work

> **I build in code. I paint in light.**

## Creative Work

### Projection Mapping

I use projection mapping as a way to turn ordinary physical spaces into dynamic visual environments.

My visual work is heavily influenced by psychedelic and experimental music, particularly artists such as:

- Pink Floyd
- Porcupine Tree
- The Strokes
- Nirvana
- Guns N' Roses

The goal is not simply to project an image onto a surface, but to create an experience where **light, space, music, and motion interact**.

## Local Development

If you want to run the portfolio locally:

```bash
git clone https://github.com/yuvi1-1/echoes_in_light.git
cd echoes_in_light
```

If the project is a static HTML site, open `index.html` directly in a browser.

For a local development server, you can use:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
